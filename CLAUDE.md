This is a personal chord sheet reader for my own live guitar performances.

I am not a developer. Explain everything in plain language. Never assume I can
debug. Ask before anything hard to reverse. Keep this project as small as
possible and refuse to add features I have not asked for.

RULES THAT NEVER CHANGE

1. This app never downloads, fetches or scrapes anything from any website. Every
   input is a file already sitting on my own computer.
2. No copyrighted lyrics ever enter this repository, not even as test data. When
   you need example songs, invent nonsense lyrics yourself.
3. My real songs live in a folder outside the repository. Keep it gitignored.
4. This is private. Nothing is ever published or shared.

KEEP IT SIMPLE

No database. No accounts. No login. No sync service. No audio handling of any
kind. The whole library is one file my Mac produces and the app carries with it.
If a feature would need a server, tell me and stop rather than building one.
